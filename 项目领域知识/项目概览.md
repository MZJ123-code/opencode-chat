# OpenCode Chat — 项目概览

## 一句话描述

OpenCode Chat 是一个基于 OpenCode SDK 的多用户 AI 聊天服务，提供 Web 聊天界面和管理看板。

## 核心定位

将 **OpenCode**（终端 AI 编程助手）的能力通过 HTTP API + Web UI 暴露给**多用户**使用，提供类似 ChatGPT 的聊天体验，但后端驱动是 OpenCode 的 Agent 系统。

## 解决的核心问题

| 问题 | 方案 |
|------|------|
| OpenCode 默认只有终端 TUI | 提供 Web 界面（React 19 + Vite） |
| OpenCode 是单用户工具 | 多用户隔离（基于 IP） |
| OpenCode 无持久化统计 | SQLite 统计 + 看板（Dashboard） |
| OpenCode 无历史管理 | 会话列表 + 消息历史 |
| 团队共享 AI 能力 | 服务端部署，多人共用 |

## 技术栈

| 层 | 技术 | 用途 |
|----|------|------|
| 运行时 | Bun | 快速 JS 运行时，内置 `bun:sqlite` |
| 后端框架 | Express 4 (ESM) | HTTP 路由和中间件 |
| AI 引擎 | `@opencode-ai/sdk v2` | 管理 OpenCode 子进程 |
| 前端 | React 19 + TypeScript | 用户界面 |
| 构建 | Vite 6 | 前端打包 |
| 样式 | Tailwind CSS v4 | UI 样式 |
| 动画 | framer-motion | 界面动画 |
| 图表 | recharts | 看板图表 |
| 存储 | SQLite (bun:sqlite) + 内存 Map | 数据持久化 |
| 日志 | 自定义文件轮转 | 调试和监控 |

## 功能列表

- 多会话管理（创建、列出、切换）
- 多 Agent 选择（知识向导/代码构建/架构规划/代码探索）
- 异步消息流（SSE 实时推送，20+ 事件类型）
- 同步/异步双模式聊天 API
- 会话子任务导航（task 工具创建的子会话，导航栈支持）
- 权限弹窗（允许/拒绝/始终允许）
- 多步问答表单（单选/多选/自定义输入）
- 满意度反馈（赞/踩）
- 管理看板（按日统计、Agent 分布饼图、满意度分析、访问/提问/反馈明细）
- 暗色/亮色主题切换
- 文件系统作为知识库（知识向导 Agent，独立工作目录）
- 基于 IP 的多用户隔离
- 限流保护（200 次/15 分钟/IP）
- 7 天会话 TTL 自动清理
- Vanilla JS 回退前端（无 React 构建时可用）

## 适合场景

- 企业内部小团队快速搭建 AI 助手
- 需要看板统计的管理场景
- 以文件系统为知识库的文档问答场景
- 需要多 Agent 切换的研发团队
- 不想部署复杂认证系统的内部工具

## 不适合场景

- 面向公网的多用户 SaaS 服务（无认证、IP 识别不可靠）
- 需要高可用和数据不丢失的生产系统（内存存储无持久化）
- 移动端主要使用场景（无 PWA、触控优化不足）
