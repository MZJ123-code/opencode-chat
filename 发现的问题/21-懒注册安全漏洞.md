# 21. 懒注册导致安全漏洞

> **严重度**：🟡 关注
> **涉及文件**：`server/middleware/sessionGuard.js`、`server/services/sessionService.js:175`
> **类型**：安全

## 问题描述

`sessionGuard.js` 实现了"懒注册"机制，允许一个不拥有会话的用户尝试注册它：

```js
// sessionGuard.js:28-35
if (validateOwnership(ip, sessionId)) return next()

// 本地未找到，尝试从 OpenCode SDK 懒注册
tryRegisterSession(ip, sessionId)
  .then((registered) => {
    if (registered) return next()
    // 最终拒绝...
  })
```

```js
// sessionService.js:175-191
export async function tryRegisterSession(ip, sessionId) {
  if (sessionMeta.has(sessionId)) return true  // 已有则跳过
  const user = ipUsers.get(ip)
  if (!user || user.sessionIds.size === 0) return false  // 只有已有会话的用户才能尝试
  
  try {
    const client = getClient()
    await client.session.messages({ sessionID: sessionId })  // 验证会话存在
    // 如果会话存在，任何人都能注册！
    sessionMeta.set(sessionId, { ip, ... })
    user.sessionIds.add(sessionId)
    return true
  } catch { return false }
}
```

### 漏洞

1. 任何有一定会话的用户都可以尝试访问任何存在的会话
2. 验证只检查会话是否存在（`client.session.messages()` 不检查权限），存在即可注册
3. 一旦注册成功，该 IP 就永久获得该会话的访问权限

## 改进方向

1. 移除懒注册机制，只允许通过主动创建会话获得访问权限
2. 或使用基于签名的 session token 替代 IP 校验
