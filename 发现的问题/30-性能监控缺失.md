# 问题 30：性能监控缺失

## 严重程度
🟠 中等

## 问题描述

没有性能监控机制，无法实时监控系统性能，无法及时发现性能问题。

## 问题详情

### 当前状态

- 没有性能指标收集
- 没有实时监控
- 没有告警机制
- 无法及时发现性能问题

### 问题分析

1. **无法实时监控**
   - 没有 CPU 使用率监控
   - 没有内存使用率监控
   - 没有请求延迟监控

2. **无法及时发现问题**
   - 没有告警机制
   - 无法提前预警
   - 可能在用户投诉后才发现问题

3. **无法优化性能**
   - 没有性能基线
   - 无法对比优化效果
   - 无法确定瓶颈

## 影响

- 无法及时发现性能问题
- 无法提前预警
- 无法优化性能

### 方案 A：添加性能指标收集

```typescript
// server/middleware/metrics.ts
import { Registry, Counter, Histogram, Gauge } from 'prom-client';

const register = new Registry();

// 请求计数
export const httpRequestsTotal = new Counter({
  name: 'http_requests_total',
  help: 'Total number of HTTP requests',
  labelNames: ['method', 'route', 'status'],
  registers: [register],
});

// 请求延迟
export const httpRequestDuration = new Histogram({
  name: 'http_request_duration_seconds',
  help: 'Duration of HTTP requests in seconds',
  labelNames: ['method', 'route'],
  buckets: [0.01, 0.05, 0.1, 0.5, 1, 5],
  registers: [register],
});

// 活跃连接数
export const activeConnections = new Gauge({
  name: 'active_connections',
  help: 'Number of active connections',
  registers: [register],
});

// SSE 事件计数
export const sseEventsTotal = new Counter({
  name: 'sse_events_total',
  help: 'Total number of SSE events',
  labelNames: ['type'],
  registers: [register],
});

// 中间件：收集指标
export function metricsMiddleware(req, res, next) {
  const start = Date.now();
  
  res.on('finish', () => {
    const duration = (Date.now() - start) / 1000;
    const route = req.route?.path || req.path;
    
    httpRequestsTotal.inc({
      method: req.method,
      route,
      status: res.statusCode,
    });
    
    httpRequestDuration.observe({
      method: req.method,
      route,
    }, duration);
  });
  
  next();
}

// 指标端点
app.get('/metrics', async (req, res) => {
  res.setHeader('Content-Type', register.contentType);
  res.end(await register.metrics());
});
```

### 方案 B：添加性能日志

```typescript
// server/middleware/performanceLogger.ts
export function performanceLogger(req, res, next) {
  const start = Date.now();
  
  res.on('finish', () => {
    const duration = Date.now() - start;
    const log = {
      timestamp: new Date().toISOString(),
      method: req.method,
      path: req.path,
      statusCode: res.statusCode,
      duration,
      ip: req.clientIP,
      userAgent: req.headers['user-agent'],
    };
    
    // 记录慢请求
    if (duration > 1000) {
      logger.warn('Slow request', log);
    }
    
    // 记录所有请求
    logger.info('Request', log);
  });
  
  next();
}
```

### 方案 C：添加告警机制

```typescript
// server/services/alertService.ts
export class AlertService {
  private static instance: AlertService;
  private alerts: Map<string, Alert> = new Map();
  
  static getInstance(): AlertService {
    if (!AlertService.instance) {
      AlertService.instance = new AlertService();
    }
    return AlertService.instance;
  }
  
  // 检查性能指标
  checkMetrics(metrics: Metrics) {
    // CPU 使用率告警
    if (metrics.cpuUsage > 80) {
      this.sendAlert('HIGH_CPU', `CPU usage is ${metrics.cpuUsage}%`);
    }
    
    // 内存使用率告警
    if (metrics.memoryUsage > 80) {
      this.sendAlert('HIGH_MEMORY', `Memory usage is ${metrics.memoryUsage}%`);
    }
    
    // 请求延迟告警
    if (metrics.avgRequestDuration > 1000) {
      this.sendAlert('HIGH_LATENCY', `Average request duration is ${metrics.avgRequestDuration}ms`);
    }
    
    // 错误率告警
    if (metrics.errorRate > 5) {
      this.sendAlert('HIGH_ERROR_RATE', `Error rate is ${metrics.errorRate}%`);
    }
  }
  
  // 发送告警
  sendAlert(type: string, message: string) {
    const alert = this.alerts.get(type);
    if (alert && Date.now() - alert.lastSent < 300000) {
      return; // 5 分钟内不重复发送
    }
    
    // 发送告警（邮件、Slack、钉钉等）
    console.log(`[ALERT] ${type}: ${message}`);
    
    this.alerts.set(type, {
      type,
      message,
      lastSent: Date.now(),
    });
  }
}
```
