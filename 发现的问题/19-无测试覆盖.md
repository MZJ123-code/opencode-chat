# 19. 无测试覆盖

> **严重度**：🟡 关注
> **涉及文件**：全项目
> **类型**：工程

## 问题描述

项目没有任何测试文件：

- 无单页测试
- 无集成测试
- 无 E2E 测试
- 无 API 测试

### 风险

| 场景 | 风险 |
|------|------|
| 修改中间件链 | 可能破坏请求处理流程，无法被自动检测 |
| 修改 sessionService | 限额逻辑、淘汰策略、TTL 清理可能出错 |
| 修改事件处理 | 20+ 事件类型的处理逻辑可能被破坏 |
| 重构 ChatContext | 无测试保障重构的正确性 |
| 升级依赖 | 无法判断新版本是否破坏了现有功能 |
| 新人加入 | 无测试作为行为文档，不敢修改代码 |

## 改进方向

```bash
# 后端测试
vitest + supertest
  → 测试中间件链（clientIP → requestLogger → rateLimiter → routes）
  → 测试 sessionService 限额/淘汰/TTL
  → 测试 statsService 和 analyticsService 的 CRUD

# 前端测试
vitest + @testing-library/react
  → 测试 ChatContext 的核心状态变换
  → 测试 useEvents 的事件分发逻辑
  → 测试 Dashboard 组件的筛选/排序

# 集成测试
  → SSE 事件流的完整链：SDK → events.js → SSE → useEvents → ChatContext
```
