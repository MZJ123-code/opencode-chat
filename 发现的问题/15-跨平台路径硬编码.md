# 15. 跨平台路径硬编码

> **严重度**：🟡 关注
> **涉及文件**：`server/config.json`
> **类型**：配置

## 问题描述

```json
{
  "agentOptions": [
    {
      "label": "知识向导",
      "directory": "D:/workspace/knowledge-base"   // ← Windows 绝对路径
    }
  ]
}
```

### 问题

- macOS/Linux 下不存在 `D:/` 盘符，知识库功能不可用
- 默认配置直接包含 Windows 路径，新用户 clone 后需要手动修改
- Git 仓库中不应该包含特定机器的绝对路径

## 改进方向

1. 使用相对路径：`"directory": "./knowledge-base"`
2. 支持环境变量占位符：`"directory": "${KNOWLEDGE_BASE_PATH}"` 
3. 默认值设为 `""`（不配置独立目录），用户按需配置
