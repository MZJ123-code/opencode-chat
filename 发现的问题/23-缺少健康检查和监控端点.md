# 23. 缺少健康检查和监控端点

> **严重度**：🟡 关注
> **涉及文件**：无（缺少端点）
> **类型**：运维
> **状态**：✅ 已解决

## 问题描述

项目没有提供运维所需的接口：

- 无 `GET /health` 健康检查端点
- 无 `GET /metrics` 监控指标端点
- 无 Prometheus 兼容格式输出
- 无进程资源使用情况报告

### 影响

- Docker/K8s 部署时无法进行健康检查（liveness/readiness probe）
- 无法监控 OpenCode 子进程的运行状态
- 无法排查内存泄漏或文件描述符泄漏问题
- 收到用户投诉无法快速定位服务是否正常
