# 问题 25：性能测试框架缺失

## 严重程度
🟠 中等

## 问题描述

当前缺少性能测试框架，无法量化响应时间、吞吐量等关键性能指标，无法检测性能回归。

## 问题详情

### 当前状态

- 没有性能测试用例
- 没有基准测试数据
- 没有性能监控
- 无法检测性能退化

### 问题分析

1. **无法量化性能**
   - 没有 API 响应时间测试
   - 没有 SSE 事件延迟测试
   - 没有并发用户测试

2. **无法检测性能回归**
   - 代码修改可能导致性能退化
   - 手动测试无法覆盖所有场景
   - 可能在发布后才发现性能问题

3. **无法对比不同版本**
   - 无法对比 v1.0 和 v2.0 的性能
   - 无法确定升级是否带来性能提升
   - 用户无法做出 informed 决策

## 影响

- 可能发布性能退化的版本
- 无法追踪性能优化效果
- 用户无法评估系统性能

## 改进建议

### 方案 A：添加 API 性能测试

```typescript
// server/__tests__/performance/api.test.ts
import request from 'supertest';
import { app } from '../../index';

describe('API Performance', () => {
  it('should handle 100 concurrent requests under 2s', async () => {
    const startTime = Date.now();
    const promises = [];

    for (let i = 0; i < 100; i++) {
      promises.push(
        request(app)
          .get('/api/sessions')
          .set('X-Forwarded-For', `192.168.1.${i % 255}`)
      );
    }

    await Promise.all(promises);
    const duration = Date.now() - startTime;

    console.log(`100 requests completed in ${duration}ms`);
    expect(duration).toBeLessThan(2000);
  });
});
```

### 方案 B：添加 SSE 性能测试

```typescript
// server/__tests__/performance/sse.test.ts
import EventSource from 'eventsource';

describe('SSE Performance', () => {
  it('should deliver events within 100ms', async () => {
    const eventTimes: number[] = [];
    const es = new EventSource('http://localhost:3000/api/events');

    es.onmessage = (event) => {
      const receiveTime = Date.now();
      const sendTime = JSON.parse(event.data).timestamp;
      eventTimes.push(receiveTime - sendTime);
    };

    // 等待收集足够数据
    await new Promise(resolve => setTimeout(resolve, 5000));
    es.close();

    const avgLatency = eventTimes.reduce((a, b) => a + b, 0) / eventTimes.length;
    console.log(`Average SSE latency: ${avgLatency}ms`);
    expect(avgLatency).toBeLessThan(100);
  });
});
```

### 方案 C：添加负载测试

```typescript
// server/__tests__/performance/load.test.ts
import autocannon from 'autocannon';

describe('Load Testing', () => {
  it('should handle 1000 requests/second', async () => {
    const result = await autocannon({
      url: 'http://localhost:3000/api/sessions',
      connections: 10,
      duration: 10,
      pipelining: 10,
    });

    console.log(`Requests/sec: ${result.requests.average}`);
    expect(result.requests.average).toBeGreaterThan(1000);
  });
});
```

### 方案 D：添加 CI/CD 集成

```yaml
# .github/workflows/performance.yml
name: Performance

on: [push, pull_request]

jobs:
  performance:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'

      - name: Install dependencies
        run: bun install

      - name: Start server
        run: bun run dev &
        env:
          PORT: 3000

      - name: Wait for server
        run: sleep 5

      - name: Run performance tests
        run: bun test server/__tests__/performance/

      - name: Run load tests
        run: bun run load-test
```
